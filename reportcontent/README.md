# 历史实验与报告生成源码

这里只保留脚本，没有报告结果、截图、测量数据、ZIP、进程状态、生成场景和安装快照。
这些历史工具没有在本次导出中执行或迁移。

- `report_mesh_comparison_20261002/`：从项目模型资源生成网格对比图的脚本。
- `benchmark_20261002/`：历史 Gazebo benchmark。需要构建后的 ROS 工作区、原 Git 历史
  （包括脚本引用的历史提交）及 `old_cap_robot` 中的历史 SO101 资源。仅凭本源码包不能完整复现。
- `report_scenes/`：历史场景辅助脚本，依赖未包含的 scene_manifest.json、旧路径和当时的场景资产。
  重用前需重新准备输入，不能直接拿旧会话状态运行。

这些脚本不是正式 ACT/PPO 训练或 S0–S5 评估入口。
